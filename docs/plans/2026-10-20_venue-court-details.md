# 场馆球场信息调研（2026-10-20）

调研方式：网络检索 + 直接读取官方页面（ClubSpark 场馆页、LTA "Play" 订场页、ClubSpark 订场接口 `GetVenueSessions` 返回的每块场地属性、各区议会页面、运营方页面）。未执行任何 SQL。

图例：
- 场地数 = 可订成人网球场数量（不含 mini court）。
- 室内/室外：`outdoor` / `indoor` / `mixed`。
- 灯光：`true` = 有来源明确说有灯光场；`false` = 有来源明确说没有灯光；`null` = 无法确认。
- 置信度：高 = 官方页面文字直接写明；中 = 多个间接信号一致但无一句明确文字；低/未知 = 留空。
- "ClubSpark 场地数据" 指 `https://clubspark.lta.org.uk/v0/VenueBooking/<slug>/GetVenueSessions?...` 返回的每块场地的 `Lighting` 字段（1 = 有灯，0 = 无灯或未填）。在有文字可核对的场馆（Clapham、Finsbury、Burgess、GMH、Kennington、Southwark、Tanner St），这个字段都和文字一致；只有它一个来源时不单独作为 `false` 的依据。
