# Tennis Match 页面功能与操作流程

> 基于 `main` 分支 `c0bb416`（Add bilingual booking assistant account and partner flows）整理，供页面改版时对照，避免丢失功能。

整站是一个单页应用（`app/page.tsx` 的 `TennisSocialApp`），通过 URL 参数切换视图：

| 视图 | URL | 组件 |
|---|---|---|
| 首页 | `/` | `components/views/home-view.tsx` |
| 场次详情 | `/?view=detail&session=<id>` | `detail-view.tsx` |
| 报名（填写 / 支付） | `/?view=booking&session=<id>&stage=payment` | `booking-view.tsx` |
| 报名成功 | `/?checkout=success&session=<id>`（Stripe 回跳） | `confirmation-view.tsx` |
| 场地 / 球友预约申请 | `/?view=request` | `request-view.tsx` |
| 账户 | `/?view=account` | `account-view.tsx` |
| 管理后台 | `/admin` | `admin-view.tsx` |

全站通用：顶部导航（品牌标识 → 回首页、`中文/En` 语言切换并记住偏好、登录/账户入口），页脚（Stripe 支付说明，首页显示「Admin portal」入口）。

---

## 1. 首页

### 1.1 首屏介绍区
- 眉标「FIND YOUR NEXT COURT」+ 主标题 + 简介文案。
- 两个卖点标签：**All levels welcome**、**Court booked for you**。
- **预约申请入口**（`request-cta`）：主文案「Looking for a court and tennis partners? Request one!」+ 副文案「Tell us your preferred court and time.」→ 打开预约申请页。
- **Explore sessions** 按钮 → 平滑滚动到场次列表（遵循系统「减少动态效果」设置）。
- 右侧三张球场照片拼贴 + 「PLAY *more*」贴纸，悬停有动效。

### 1.2 场次列表（`#sessions`）
- 只显示 **已发布（published）且未过期** 的场次，按时间排序。
- 标题区：伦敦当地时间提示、「Upcoming sessions」、说明文案、右侧「N sessions available」计数（加载中显示「Loading sessions…」）。
- 空状态：加载中 / 暂无场次。

### 1.3 场次卡片（每张卡片的全部信息）
| 元素 | 规则 |
|---|---|
| 场地照片 | 点击进入详情；不显示翻页按钮 |
| 日期徽章 | 日 + 月份缩写（按语言本地化） |
| **Full 徽章** | 名额为 0 时显示 |
| **时长徽章** | **场次时长 ≥ 2 小时** 时显示，如「2h session」/「2小时场」、「2.5h session」 |
| 区域 + 场地名 | `venue.area` 眉标 + 场地名称 |
| 地址摘要 | 地图图标 + 地址 · 邮编（中文优先用中文地址，缺省回退到区域） |
| 价格 | 「£X / person」（中文「/ 人」） |
| 日期 + 时间 | 完整日期、`开始–结束` |
| 比赛形式标签 | Singles / Doubles |
| **「Match players」寻找球友区** | 见下方 1.4 |
| 剩余名额 | 「N spots left」；**只剩 1 个时以紧急样式**显示；满员显示 Full |
| 主按钮 | 有名额：「Book a place」；满员：按钮置灰（outline + disabled），文案为「View details」 |

### 1.4 「寻找什么水平的球友」（Match players）
- 来源合并：
  1. 管理员手动设置的 `session.seekingLevels`，与该场次的每种形式组合（如 3.0 × 单打、3.0 × 双打）；
  2. 已报名者的水平与形式偏好（`session.bookingPreferences`，无则从 bookings 推算），按 **水平 + 形式** 汇总。
- 按「水平 + 形式」去重，手动设置优先。
- 每条显示为「Looking for **{level}** level (**{format}**)」/「寻找{level}水平（{format}）」，**人数 > 1 时追加「×N」**。
- 没有任何偏好时整块不显示。

### 1.5 预约助手（仅首页）
- 右下角「Court request assistant」悬浮按钮，打开聊天面板（需配置 `GEMINI_API_KEY`）。
- 中英双语；收集场地/时间、找球友需求、水平、单双打偏好，提交为预约申请，球友需求写入申请备注。
- 未登录用户可在聊天内 **注册 / 登录 / 以访客提交**；注册会复用已收集的信息。密码只发往账户接口，不进入模型消息和浏览器存储。
- 模型临时错误有限次重试，再切换备用模型；助手不会声称“已订好”。

## 2. 场次详情页
- 「Back to sessions」返回。
- 场地照片画廊（多图可左右切换，显示 `1/3`）+ 场地名 · 区域说明。
- 信息格：日期、时间（伦敦时间）、**时长**、比赛形式、剩余名额、每人价格。
- 「无水平限制 · All levels welcome」提示。
- 完整地址 + 「Open in Google Maps」外链。
- **Share session**：优先使用系统分享，失败时复制链接，并显示提示。
- **Book a place**（满员时禁用）→ 进入报名流程。
- 底部「About this session」场次介绍（中英各自的描述）。

---

## 3. 报名与支付流程
1. **填写信息（第 1 步）**
   - 顶部进度条：1 填写信息 → 2 支付。
   - 联系人：姓名、邮箱、电话（登录用户自动预填，并提示已预填）。
   - 比赛形式：只能选场次提供的形式（默认选中用户偏好的形式）。
   - 参与者：自己的水平；可勾选「带朋友」，增减人数并为每位朋友选择水平；人数不能超过剩余名额。
   - 球拍租借（后台开关 `racketRentalEnabled`，£2/支）：数量不超过总人数。
   - 右侧订单摘要：场次费、球拍费、会员折扣 / 优惠券、总价。
   - 未登录时提示可以注册保存信息。
2. **支付（第 2 步）**
   - 再次校验：场次仍已发布、未过期、形式可选、名额足够，不满足则退回第 1 步并显示原因。
   - 调用 `/api/checkout`，服务端按便士计算价格，并锁定名额 30 分钟 → 跳转 Stripe Checkout。
   - 处理失败 / 取消 / 名额冲突（409）/ 优惠券失效等提示。
3. **报名成功页**（Stripe 回跳 `?checkout=success`）
   - 订单号、场次信息、参与者及水平、球拍、折扣、总价。
   - 确认邮件状态：已发送 / 发送中 / 失败 / 跳过；邮件附带 `.ics` 日历文件，开场前一晚 18:00 发送提醒。
   - 引导创建账户以管理报名、继续浏览其他场次。

## 4. 场地 / 球友预约申请
- 入口：首页 CTA、预约助手。
- 申请类型：**指定场地**（输入场地名，支持中英文名自动补全和键盘上下选择）或 **找附近场地**（填伦敦邮编，会校验格式）。
- 期望日期（不早于今天）、开始 / 结束时间（结束需晚于开始）、留言。
- 联系人：姓名、邮箱（必填）、电话（可选）。
- 提示：**提前 7 天及以上的申请可以保证安排**，7 天内无法保证。
- 提交成功后显示申请编号，并提示注册账户。

---

## 5. 账户
- 登录 / 注册（姓名、邮箱、密码、电话、邮编、网球水平、偏好形式、偏好时段）。
- 个人资料查看与编辑、退出登录。
- 会员信息：注册时间、参与次数、奖励进度；**完成 10 场已付费场次后永久享受 9 折**（只对场次费生效）；旧版优惠券可通过环境变量开启。

---

## 6. 管理后台（`/admin`）
- 管理员登录（签名 Cookie）。
- 场次：列表 / 一周日历视图；按日期、场地、状态筛选；新建 / 编辑（已有确认报名时会锁定部分字段）；批量发布 / 设为草稿（可撤销）；按 4 周重复生成；Excel 导入（提供模板和校验报告）；导出 CSV；可选择显示已过期场次；设置寻找球友的水平（`seekingLevels`）。
- 场地：多图（上传 ≤1 MB 或填 URL）、高峰 / 非高峰价格、地址与备注。
- 报名记录：查看水平、形式、球拍；一键取消并释放名额。
- 预约申请：状态流转（New / In Review / Completed）。
- 设置：球拍租借开关；一键重置演示数据。
